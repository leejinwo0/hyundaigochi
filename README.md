# 기름만 줘도 잘 커요

**차량 신호로 내 차(도트 캐릭터)를 키우는 Pleos Connect 차량용 앱**입니다.
현대자동차그룹 차량용 앱 개발 공모전(개인, 일반 부문) 출품작이며, 공식 서비스가 아닌 **비공식 출품작**입니다.

달린 만큼 차가 자랍니다. 비가 오면 와이퍼를, 누가 타면 좌석을, 얼마나 달렸는지는 주행거리를 차량이 알려 주고,
앱은 그 신호로 능력치와 레벨을 올립니다. 급가속·급감속·안전벨트 미착용 같은 위험 운전은 안전 능력치를 깎습니다.

## 주요 기능

- 달린 만큼 성장: 주행거리, 날씨, 동승자, 공조, 창문 등 차량 신호로 능력치 6개와 15단계 레벨이 오릅니다.
- 위험 운전은 안전 능력치와 컨디션을 깎습니다. (새 차는 안전 99, 나머지 0에서 시작)
- 주행 중에는 멈춰 있는 도트 차와 "기록 중"만 보이고, 정차(P) 중에만 기록과 정산을 열람합니다.
- 앱을 열지 않아도 주행은 쌓이고, 다음에 열면 한꺼번에 정산합니다.
- 주행마다 경험치와 능력치가 얼마나, 왜 바뀌었는지 계산 내역을 보여 줍니다.
- 시즌(한 달, 시연 모드에서는 3회 주행) 성적표와 다음 시즌 목표 선택.
- 차종 8종, 색상 12가지, 별명, 번호판(선택), 용도(최대 3개), 출고 연월·연료 종류(선택).

## 실행 방법

1. Android Studio에서 이 폴더를 엽니다. (Open)
2. Gradle Sync 가 끝나면 Pleos Connect 에뮬레이터를 실행합니다. (아래 테스트 환경 참고)
3. ▶ Run 으로 설치합니다.

APK로 설치하려면 `apk/` 폴더의 release APK를 사용합니다.

```
adb install -r apk/이진우_기름만줘도잘커요_release.apk
```

## 테스트 환경·설정

- Android Studio, Kotlin, Jetpack Compose, minSdk 28
- 에뮬레이터: Pleos Connect Emulator v2.1.0 (API 34), Cold boot, RAM 4GB
- Pleos SDK: `ai.pleos.playground:Vehicle:2.3.2`
  (Maven: `https://nexus-playground.pleos.ai/repository/maven-releases/`, `settings.gradle.kts` 에 설정되어 있음)
- 차량 상태 바꿔 보기: Pleos Connect Virtual Console

```
adb forward tcp:8088 tcp:8088
```

  브라우저에서 `http://127.0.0.1:8088/` 를 엽니다.

### 시연 순서 (예)

1. 앱 첫 실행: 모습, 별명·용도, 내 차 소개(선택), 집중 육성을 고릅니다.
2. Virtual Console에서 기어를 **D** 로 바꿉니다. 앱에는 "기록 중"만 남습니다.
3. 와이퍼를 켜고, 뒷문을 열고 닫고, Odometer 를 조금 올립니다. (안전벨트는 Telltales 에서 조작)
4. 기어를 **P** 로 바꾸면 정산 화면이 나옵니다.
5. 주행 기록에서 줄을 눌러 경험치와 능력치 계산 내역을 봅니다.
6. 내 차 탭에서 **시연 모드**를 켜면 3회 주행마다 시즌 성적표가 나옵니다.

## 사용한 차량 신호와 권한

| 차량 신호 | 앱에서 쓰이는 곳 |
|---|---|
| Odometer | 달린 거리, 성장 |
| Wiper | 빗길 경험 (적응력) |
| Light (하향등) | 밤길 경험 (적응력) |
| HVAC, 좌석·핸들 열선 | 히터, 에어컨 경험 (적응력) |
| 좌석 착석, 뒷문 | 동승자 경험 (사교성) |
| 앞 창문 | 창문 열고 달리기 (모험심) |
| 좌석 벨트, Safety | 안전벨트 미착용 (안전, 컨디션) |
| EV 배터리 / 연료 잔량 | 배고픈 표정 |
| 차속 (AAOS 표준, 런타임 권한) | 급가속·급감속 감지 |
| 기어 (AAOS 표준) | 주행 중/정차 중 구분 |

선언한 권한: `pleos.car.permission.CAR_DRIVE`, `CAR_WINDOWS`, `CAR_LIGHTS`, `CAR_CLIMATE`, `CAR_SEATS`, `CAR_SAFETY`,
`CAR_DOORS`, `CAR_ENERGY`, 그리고 `android.car` 의 `CAR_POWERTRAIN`, `CAR_SPEED`.
앱의 **내 차 → 차량 연결 상태**에서 각 신호가 실제로 들어오는지(✓/✕) 확인할 수 있습니다.

## 개인정보

- 주행 기록과 설정은 **기기 안에만** 저장하며 서버로 보내지 않습니다.
- 번호판은 선택 입력이며 기기 안에만 저장됩니다. **내 차** 탭에서 수정·삭제할 수 있습니다.
- **내 차 → 내 데이터 모두 지우기**로 모든 기록을 지울 수 있습니다.

## 안내

- 차종 이름은 공모 주제를 설명하기 위한 표기이며, 도트 그림은 직접 그렸고 로고와 엠블럼은 사용하지 않았습니다.
- 위험 운전을 부추기는 보상은 없고, 게임 화면은 정차 중에만 열립니다.
